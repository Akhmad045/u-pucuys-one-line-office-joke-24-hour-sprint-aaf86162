## The joke

> I wrote 'per my last email' today and felt my soul quietly file for early retirement.

One single line about office life (85 characters) — the sort of line you send a
colleague after a meeting that should have been an email.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the joke to
`/output/entry.txt`, validating that it is a single non-blank line of 1–200
UTF-8 characters with no control characters and no leading or trailing
whitespace, then verifies the written bytes round-trip exactly.

Run it with:

```sh
python3 main.py
```
